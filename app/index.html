Project inventory (sample)

Paste the output of supabase projects list --output json. See which organization holds what, which projects are paused, and a rough monthly cost per organization. Nothing leaves your browser.
The CLI output has no plan and no "last used" date. Choose each organization's plan yourself. "Dormant candidate" = paused and at least 90 days old: a prompt to look, not proof that nobody uses it. Cost is a rough estimate (plan fee + $10 per active project - $10 included; see the article for the date of these prices).
